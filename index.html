🧠 The Google & FAANG 8-Step Problem-Solving Approach
Systematic Framework

Google interviewers test your structured thought process rather than raw memorization. Follow these 8 non-negotiable steps for every problem:

01
Clarify & Constraints
Ask: Bounds of N, range of values, negative numbers, empty arrays, duplicate handling, memory limits.
02
Examples & Edge Cases
Manually construct at least 3 cases: small base case (N=0, 1), standard case, and extreme/adversarial boundary case.
03
Brute Force & Bottleneck Analysis
State naive solution first and its Big-O. Explain why it fails and where the repetitive work occurs.
04
Pattern & Optimal Invariants
Identify data structure fit: Monotonic Stack, Two Pointers, Sliding Window, Topo Sort, Trie, Union-Find, DP.
05
Big-O Complexity Proof
Formulate exact Time and Space trade-offs with the interviewer before typing a single character of code.
06
Production-Grade Clean Code
Write modular, self-documenting code with meaningful variable names and defensive bounds-checking.
07
Manual Dry Run Line-By-Line
Step through your code using a state table on a sample test input. Catch off-by-one errors before running.
08
Post-Mortem & Spaced Repetition
Summarize the core mental model in your notes. Schedule spaced reviews at Day 1, Day 3, and Day 7.
